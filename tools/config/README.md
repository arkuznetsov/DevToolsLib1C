# Конфигурационные файлы инструментов (сборки, тесты и т.п.)

- [**vRunner.json**](./vRunner.json) - пример файла настройки инструмента Vanessa-runner для выполнения сборки конфигураций и запуска тестов
- [**ADDParams.json**](./ADDParams.json) - пример файла настройки запуска сценарных (BDD) тестов с использованием Vanessa-ADD
- [**VAParams.json**](./VAParams.json) - пример файла настройки запуска сценарных (BDD) тестов с использованием Vanessa-automation
- [**smokeTestConf.json**](./smokeTestConf.json) - пример файла настройки запуска дымовых (smoke) тестов с использованием Vanessa-ADD
- [**unitTestConf.json**](./unitTestConf.json) - пример файла настройки запуска модульных (unit) тестов с использованием Vanessa-ADD
