# Тесты и тестовые данные

- [**features**](./features) - каталог feature-файлов сценарных тестов (BDD)

- [**smoke**](./smoke) - каталог обработок и настроек дымовых (smoke) тестов
- [**unit**](./unit) - каталог обработок и настроек модульных (unit) тестов
