
# Библиотека инструментов разработки

## Назначение каталогов и файлов

- [**src**](./src) - каталог хранения исходников конфигураций/расширений
  - [**main**](./src/main) - каталог исходников конфигурации "1С: Библиотека стандартных подсистем"
  - [**dtl**](./src/dtl) - каталог исходников расширения "Библиотека инструментов разработки"
- [**tests**](./tests) - каталог тестов и тестовых данных
  - [**features**](./tests/features) - каталог feature-файлов сценарных тестов (BDD)
  - [**smoke**](./tests/smoke) - каталог обработок и настроек дымовых (smoke) тестов
  - [**unit**](./tests/unit) - каталог обработок и настроек модульных (unit) тестов
- [**tools**](./tools) - каталог инструментов (скрипты и пр.)
  - [**1CFilesConverter**](./tools/1CFilesConverter) - модуль (submodule) со скрипками конвертации конфигураций 1С
  - [**config**](./tools/config) - каталог конфигурационных файлов инструментов (сборки, тесты и т.п.)
  - [**pipeline**](./tools/pipeline) - каталог настроек сборочных линий (CI/CD)
  - [**scripts**](./tools/scripts) - каталог вспомогательных скриптов разработчика
- [**base1c**](./base1c) - служебный каталог для подготовки обновления конфигурации поставщика
- [**example.env**](./example.env) - пример настройки переменных окружения для скриптов (скопировать и переименовать в `.env`)
- [**.gitlab-ci.yml**](./.gitlab-ci.yml) - настройка GitLab CI для автоматической проверки запросов на слияние (mearge request) в SonarQube
- [**sonar-project.properties**](./sonar-project.properties) - шаблон настройки проекта SonarQube (изменить на параметры проекта)
- [**Jenkinsfile_ci**](./Jenkinsfile_ci) - пример файла настройки сборочной линии Jenkins для проверки, запуска тестов и сборки конфигурации (с использованием vanessa-usher jenkins lib)
