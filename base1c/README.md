# Служебный каталог для обновления конфигурации поставщика

- Скопировать в каталог [base1c](.) полный файл конфигурации поставщика `1cv8.cf`
- Создать или обновить ветку, в которой будет выполняться обновление (например, update) и убедиться, что в ветке находится именно та конфигурация, которую требуется обновить
- Выполнить скрипт [tools/scripts/prepare_update.cmd](../tools/scripts/prepare_update.cmd) и дождаться окончания выполнения
- Выполнить разрешение конфликтов слияния
- Выполнить коммит результата
- после проверки результатов обновления выполнить запрос на слияние в основную ветку разработки

Переменные среды

- `V8_VENDOR_BRANCH` - имя ветки в которой размещается конфигурация поставщика
- `V8_UPDATE_BRANCH` - имя ветки в которой выполняется подготовка обновленнной конфигурации
